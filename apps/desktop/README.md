# 1Finance Desktop (Phase 3 — planned)

Tauri 2 shell around the web app. The web app is fully client-rendered against the API, so it can be built as a static
bundle and loaded by Tauri. Planned: stronghold-backed secure storage, OS notifications (no balances in content),
biometric unlock via platform plugins, auto-update via the Tauri updater, and native keyboard shortcuts.
